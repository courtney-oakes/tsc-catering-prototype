# TSC catering prototype

Static site. Deploy the contents of this folder to GitHub Pages (Settings > Pages > Deploy from a branch > main / root).

- `index.html` is the whole prototype (menu, configure item, delivery, cart, checkout, confirmation, account, company) with a Prototype / Canvas toggle.
- `fonts/` holds the Sway Display web fonts (Regular, Bold, ExtraBold). Keep it next to `index.html`.
- Inter loads from Google Fonts.

Check that your Sway Display license allows web embedding before publishing a public site.
